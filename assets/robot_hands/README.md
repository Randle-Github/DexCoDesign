# Robot hand assets

This directory contains self-contained model snapshots for the DexCoDesign morphology benchmark. `registry.json` is the source of truth for model entry points, provenance, exact upstream commits, license identifiers, handedness, and whether an entry was derived.

## Layout

Each hand directory contains:

- `source/`: an unmodified, minimal snapshot extracted from upstream;
- `models/`: portable URDF entry points when upstream paths required normalization or a standalone hand had to be extracted;
- the upstream license and README;
- both left and right entry points in `registry.json`.

Generated files are reproducible with:

```bash
python scripts/assets/prepare_robot_hands.py
python scripts/assets/validate_robot_hands.py
```

Prefer native USD entries where the vendor supplies Isaac Sim assets. Otherwise use the normalized URDF or the upstream MJCF through Isaac Sim's corresponding importer. Do not edit files under `source/`; project-specific dynamics and actuator tuning belong in DexCoDesign configuration code.

## Handedness policy

Vendor-native left/right models are used whenever available. MIDAS and RUKA-v2 currently publish one simulation geometry side; their missing left entries are generated by reflecting geometry, poses, joint axes, and inertia tensors across the palm lateral axis. These entries are explicitly marked `derived: true`.

LinkerHand L25 is intentionally excluded at the user's request.
